# V2.83 商品規格快速輸入（2026-11-26）

## 需求
批發商城 → 商品管理 → 新增商品／編輯商品，使用「快速建立商品規格」。
每一行都可以直接產生一筆規格，不需要在畫面輸入直線 `|`。
可用空白、半形減號 `-`、頓號 `、` 等分隔短代碼與規格名稱。

## 程式位置
`catalog-v231.js`：
- `parseQuickVariantInput(raw, productCode)`：將可閱讀的多行輸入轉換成商品規格物件。
- `catGenerateVariants.onclick`：點「依輸入行數自動新增規格」時，呼叫解析器，序列化到現有隱藏欄位 `catPVariants`，再呼叫 `renderVariantRows()` 顯示可編輯列。
- `parseVariants()`、`saveProduct()`：維持原有資料格式和 SQL 儲存流程；本次沒有修改 Supabase schema。
`index.html`、`admin-tools-v228.js`：V2.83 版本及 JS 快取標記 `283-auto-variant-rows`。

## 規格輸入範例
```text
A、黑色
B、灰色
```
產生兩列：
- SKU：若商品編號為 5812，則 `5812-A`，名稱 `黑色`
- SKU：`5812-B`，名稱 `灰色`

以下也都產生兩列：
```text
A 黑色
B 灰色
```
```text
A-黑色
B-灰色
```
```text
黑色
灰色
```
不含代碼的範例自動產生 `5812-001`、`5812-002`。

## 多層規格（相容舊版）
```text
尺寸 - M、L
顏色 - 黑色、灰色
```
產生四種笛卡兒組合，例如 `尺寸：M／顏色：黑色`。最多三層、最多 150 組。
舊資料曾使用 `尺寸｜單人,雙人` 輸入格式，為保持相容仍可解析，但新畫面不要求使用 `|`。

## 防呆
- 忽略空白行，每一個非空白行產生一筆商品規格；最多 150 筆。
- 同組合層的選項不得重複；同批新規格 SKU 不得重複。
- 若已有規格明細，覆蓋前跳出確認；依既有 SKU 或名稱保留加價、最低訂購量、銷售狀態。
- 產生後立即呼叫 `renderVariantRows()`，使用者可在下方逐筆編輯。
- 隱藏欄位內部序列化仍沿用 `｜`，但輸入者無須手動輸入。
