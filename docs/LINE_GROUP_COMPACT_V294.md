# 宜羿 B2B V2.94：LINE 群組管理精簡收合介面

更新日期：2026-11-27

## 需求
「批發商城 → LINE 商品推播 → 1．私人 LINE 群組」在 100 個群組時，不應將整個網頁撐得非常長。保留群組「啟用／停用推播」、商品挑選、DM 合成和發送排程功能。

## 實作
- `catalog-line-dm-v291.js`
  - 群組管理區改為摘要式收合列，預設僅顯示「共 N 群｜已啟用 M 群」及「展開群組管理」；已離開群組會另統計。
  - 只有按「展開群組管理」才顯示搜尋、精簡群組卡片與狀態按鈕。
  - 展開時可用名稱或 LINE 群組編號搜尋；大小寫不敏感、支援全形字元正規化。
  - 已啟用群組優先排序，再依最後訊息時間排列；顯示群組名稱、狀態、群組 ID 尾碼與最後訊息時間。
  - 搜尋結果維持在固定高的內層清單中捲動，外面頁面不受 100 群組影響。
  - groupPanelOpen／groupFilter 狀態會保留，群組啟用／停用後重新載入清單仍保持操作狀態。
  - 群組讀取改用 `apiPaged` 分頁取得，超過單頁數量也可完整搜尋。
  - 表單中的「發送群組」選擇框仍獨立顯示，預設收合群組管理時一樣可設定 DM 發送對象。
- `catalog-v230.css`：收合列約 62px 高，展開後清單最大高度 280px，手機 235px；列表項目縮為單行資訊＋右側操作按鈕，採內部捲動。
- `index.html` / `admin-tools-v228.js`：版本同步 V2.94，JS/CSS `build=294-line-groups-collapse` 清除舊版瀏覽器快取。

## 不變內容
- LINE Webhook／官方帳號金鑰／Supabase SQL／發送工作器皆未更動。
- 不動 LINE 群組啟用狀態或任何正式 LINE 發送資料。
- DM 圖片合成、商品搜尋選取最多六件、排程、歷史紀錄與取消維持原功能。
- 點「啟用推播／停用推播」仍需確認，權限和資料庫 API 保持一致。

## 驗證
- 使用最新 GitHub 前端程式測試 JavaScript 語法。
- 使用 100 個模擬 LINE 群組檢查：
  - 摘要「共 100 群｜已啟用 20 群」正確；
  - 預設收合；展開按鈕可開啟；
  - 搜尋「批發群組 045」只會顯示一筆；
  - 收合／展開後仍保留搜尋條件；
  - 群組操作事件、LINE 商品 DM 合成與排程程式碼均保留。
- 確認 280px／手機 235px CSS 最大高度、V2.94 版號與快取引用。
- **尚未用真實登入的瀏覽器/iPad 在正式站執行 UI 手動捲動測試**；功能結構與程式檢查已通過。
